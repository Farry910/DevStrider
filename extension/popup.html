Bid Assistant

One button on any job page. It reads the job description, generates your resume through a background ChatGPT tab, builds the file with Word invisibly, and records the bid — without you leaving the page.

Ctrl+click the button instead to use text you’ve selected by hand, for pages the scraper can’t read.

Needs DevStrider running at http://127.0.0.1:8765, one logged-in ChatGPT tab open in the background, and a profile with a Word document, macro name, and resume prompt set in DevStrider · Profiles.
